[h1]Watcher[/h1]
It's a lightweight RimWorld performance monitor that helps you understand when and where the game is slowing down. Press [b]Shift+6[/b] in game to open or close the dashboard.

[img]https://files.catbox.moe/92ewpx.png[/img]

[h2]What is measured[/h2]
[list]
[*][b]FPS[/b] is calculated from Unity's unscaled frame delta. Frame time uses the same sampled value, in milliseconds.
[*][b]Tick duration[/b] is measured around [i]TickManager.DoSingleTick[/i] using a monotonic stopwatch. Average and maximum values cover the current monitoring session. The 95th percentile uses up to the latest 1,200 ticks, helping show whether slow ticks are recurring instead of highlighting only a single spike. Counts use the configured warning and critical thresholds.
[*][b]TPS[/b] is a one-second rolling observed tick rate. It is not a promise that the simulation is keeping pace with wall time.
[*][b]GC collections[/b] are session counts derived from .NET collection counters. They do not provide per-frame allocated bytes or reliable attribution to a mod.
[*][b]Memory[/b] is the managed heap size reported by [i]GC.GetTotalMemory(false)[/i]. It is not total process or GPU memory.
[*][b]Pawn/map counts and game speed[/b] are snapshots from the active game state. Pawn counts include spawned pawns on loaded maps.
[/list]

[h2]Long-tick events[/h2]
For each long tick, Watcher records the complete [i]TickManager.DoSingleTick[/i] duration along with the longest of three measured slices:
[list]
[*]Map pre-tick
[*]The [i]TickList.Tick[/i] thing/pawn batch
[*]Map post-tick
[/list]
The event shows the selected slice and its duration alongside the whole-tick duration. This helps narrow down which broad phase coincided with a slow tick.
[b]Important:[/b] this does not prove that the measured phase caused the delay, nor does it identify which mod consumed the time. Watcher does not infer mod performance attribution.
Rendering time and main-thread utilization are omitted because RimWorld does not expose reliable measurements for these to the mod.

[h2]Controls[/h2]
The dashboard provides:
[list]
[*]Current performance metrics
[*]A configurable history graph
[*]Recent long-tick events
[/list]
Settings let you configure:
[list]
[*]Long-tick threshold
[*]Critical threshold
[*]Number of retained events
[*]History window
[/list]
The event list can also be cleared directly from the dashboard.
